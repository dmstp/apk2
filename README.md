# FB Auto Poster Android v0.2 — групи, списки, виправлення кнопки

Це експериментальний Android-застосунок, який керує **офіційним Facebook** через Android AccessibilityService, а не через Facebook API.

## Нове у v0.2

- **Сканування груп**: відкриває список груп Facebook, зчитує видимі назви через AccessibilityService та прокручує екран до 100 разів або до відсутності нових результатів. Результат зберігається локально. Назви, зібрані з Facebook, можуть не містити прямих URL, а також можуть включати помилково розпізнані елементи UI — **перед публікацією перегляньте каталог**. Сканування *не гарантує* повного списку всіх груп.
- **Власні списки груп**: вибирайте галочками групи, зберігайте списки за назвою, перемикайте між списками, видаляйте списки та записи каталогу.
- **Імпорт точних URL**: вставте групи по одній на рядок (`Назва | https://www.facebook.com/groups/123/` або просто URL). Це **надійніше за сканування** та дозволяє відкривати групи напряму. Під час першого запуску старий перелік URL (з prefs `urls`) імпортується автоматично.
- **Покращений пошук кнопки**: шукає точний підпис кнопки у підтримуваних локалізаціях (UA/RU/CZ/EN), вимагає наявність редактора з уже вставленим текстом, відхиляє підписи інших кнопок `Post`, віддає перевагу справжнім кнопкам, пробує координатне натискання, якщо Accessibility ACTION_CLICK не спрацював.
- **Діагностика**: «Скопіювати діагностику кнопки» збирає доступні написи кнопок Facebook; «Скопіювати журнал публікацій» дає хід виконання.
- **Оверлей**: група, лічильник, поточна дія, кнопка «Стоп».

## Зібрати новий APK у наявному GitHub-репозиторії

1. Розпакуйте цей ZIP.
2. У своєму репозиторії **замініть** файли з ZIP із збереженням тієї самої структури (особливо `app/src/main/java/com/example/fbautoposter/`). Важливо додати **новий** `GroupsStore.kt`.
3. Перевірте `.github/workflows/build-apk.yml`: цей проєкт включає вже виправлений workflow з `android-actions/setup-android@v4` та `actions/setup-java@v5`.
4. Відкрийте вкладку Actions → Build Android APK → Run workflow.
5. В артефактах збірки розпакуйте `app-debug.apk` і встановіть на Android.

Для локальної збірки потрібні JDK 17, Android SDK 35, Gradle 8.10.2 (або використайте GitHub Actions).

## Користування

1. Увійдіть в офіційний Facebook Android.
2. Увімкніть AccessibilityService цього застосунку та дозвольте показ поверх інших застосунків.
3. Натисніть «ЗІБРАТИ ГРУПИ». Тримайте телефон розблокованим; після завершення поверніться в застосунок і натисніть «Оновити знайдені групи». При проблемах із відкриттям списку відкрийте «Мої групи» у Facebook вручну та повторіть сканування.
4. Перевірте результати, видаліть випадково знайдені елементи та за можливості додайте прямі посилання.
5. Виберіть групи галочками, натисніть «Зберегти ... як список» та назвіть його. Для завантаження списку використовуйте випадаючий перемикач.
6. Уведіть текст, API-ключ Groq (необов'язково), інтервал і режим, натисніть «ПОЧАТИ ПУБЛІКАЦІЇ».

## Обмеження та безпека

- Це прототип: реальні публікації та роботу з різними версіями Facebook ще **не перевірено**; кнопку може не вдаватися натиснути на деяких телефонах. При помилці скопіюйте діагностику кнопки для адаптації.
- Facebook не надає стабільного інтерфейсу для автоматичного отримання всіх груп через офіційний Android-застосунок. Accessibility читає лише видимі/доступні елементи. Назви без URL шукаються через екран списку груп, тож можуть не знайтися.
- Натискання `Опублікувати` **не є доказом**, що Facebook опублікував допис. Результати можуть бути непідтверджені або очікувати модерації.
- Публікується **лише текст**, фото наразі не підтримуються.
- Зберігається Groq API key в Android SharedPreferences без шифрування; застосовуйте ключ із лімітами.
- У разі оновлення раніше встановленого APK, створеного на іншому GitHub-runner, підпис debug-збірки може змінитися. Можливо, доведеться видалити старий застосунок (це видалить локальні дані). Для стабільних оновлень потрібен постійний ключ підпису.
- Автоматизація масових публікацій може порушувати правила Facebook та призвести до обмеження акаунта.
