# FB Posting Prototype (Android)

Експериментальний вихідний код Android-застосунку з AccessibilityService, Groq і оверлеєм.

## Збірка APK
1. Відкрити папку у Android Studio (JDK 17, Android SDK 35).
2. Дочекатися Gradle Sync.
3. Build > Build APK(s).
4. APK буде у `app/build/outputs/apk/debug/app-debug.apk`.

## Запуск
1. Встановити APK, дозволити Accessibility Service і "Показувати поверх інших застосунків".
2. Увійти в офіційний Facebook Android.
3. Ввести URL груп (одне посилання на рядок), текст і за бажанням Groq API key.
4. Натиснути Запустити. Не блокувати екран.

## Важливі обмеження
- Це **прототип**, не протестований на живому Facebook. Інтерфейс Facebook відрізняється за версією і мовою.
- Підтримується тільки текст, без фото, коментарів, сканування груп та планувальника.
- Немає достовірного підтвердження успіху: після натискання кнопки "Post" застосунок переходить до наступної групи; публікація може бути неуспішною.
- Розпізнавання кнопок базується на текстових підписах і може натиснути не ту кнопку; тестуйте лише у власній тестовій групі.
- Groq key зберігається в приватних SharedPreferences без додаткового шифрування. Для продакшн потрібне безпечне сховище.
- Android 13+ та політики Google Play можуть обмежувати використання AccessibilityService. Публікація через сторонню автоматизацію може порушувати правила Facebook.
- Для надійного продукту потрібні додаткові перевірки фактичної відправки, обробка помилок, кнопка паузи та підтримка різних локалізацій.

## Хмарна збірка APK через GitHub Actions (без Android Studio)

1. Створіть приватний репозиторій GitHub і завантажте **вміст папки проєкту** до кореня репозиторію (разом із `.github/workflows/build-apk.yml`).
2. У репозиторії відкрийте **Actions → Build Android APK → Run workflow**.
3. Після завершення відкрийте запуск та завантажте артефакт **FBAutoPosterAndroid-debug-APK**.
4. Розпакуйте артефакт: усередині буде `app-debug.apk`, інсталяційний файл Android.

Ця інструкція використовує віддалену збірку, не вимагає SDK на вашому комп'ютері. Для використання AccessibilityService на деяких версіях Android після встановлення APK потрібно окремо дозволити restricted settings у системних налаштуваннях. APK із цієї збірки — тестовий debug-пакет, робота з Facebook не перевірена.
